# @rich-editor/extension-page-break

Page break extension for [@rich-editor/core](https://www.npmjs.com/package/@rich-editor/core), a headless ProseMirror-based rich text editor.

## Install

```sh
npm install @rich-editor/extension-page-break @rich-editor/core
```

Most users should install [@rich-editor/starter-kit](https://www.npmjs.com/package/@rich-editor/starter-kit) instead, which bundles all extensions.

## Docs

See the [repository](https://github.com/faithdevss/rich_editor#readme) for usage and API documentation.
