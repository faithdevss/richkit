# @richkitjs/extension-drag-handle

Block drag handle for [@richkitjs/core](https://www.npmjs.com/package/@richkitjs/core), a headless ProseMirror-based rich text editor.

Gives every top-level block a Notion-style gutter: point at a block to find it, drag it to a new position with a drop indicator, and run block actions (duplicate, delete, copy, turn into) on it.

## Install

```sh
npm install @richkitjs/extension-drag-handle @richkitjs/core
```

Most users should install [@richkitjs/starter-kit](https://www.npmjs.com/package/@richkitjs/starter-kit) instead, which bundles all extensions.

The handle UI itself is a framework component — see `<BlockHandle>` in `@richkitjs/react`.
