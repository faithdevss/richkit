# Usecase: simple editor

The batteries-included starting point — a fixed toolbar over `StarterKit`, no extra
configuration. This is the shortest path from `pnpm add` to a working editor; see
[Installation](/docs/installation) for the full setup.

<AgentPrompt prompt={SIMPLE_EDITOR_PROMPT} />

```tsx
const editor = useEditor({ extensions: StarterKit, content })

<Toolbar editor={editor}>
  <ToolbarGroup>
    <ToolbarButton editor={editor} command="bold" label={<Icons.BoldIcon />} />
    {/* ... */}
  </ToolbarGroup>
</Toolbar>
<EditorContent editor={editor} />
```
