# Usecase: agent workflows

An AI agent shouldn't need a side channel into the document — it should drive the editor
through the same command chain a toolbar button uses. This demo simulates that: type an
instruction, the "agent" drafts a section as HTML and inserts it at the cursor via the
editor's normal `chain()` API, no special-cased path.

```tsx
const editor = useEditor({ extensions: StarterKit, content: AGENT_CONTENT })

// agent drafts HTML, then inserts it exactly like a user action would
editor.chain().insertContent(draftedHtml).focus().run()
```
