# Usecase: Notion-like blocks

A clean, block-based writing surface driven by `extension-slash-commands` — type `/` to
open a menu and insert headings, lists, quotes, and more without touching a toolbar.
Markdown shortcuts (`#`, `-`, `>`) work too, via `extension-markdown-shortcuts`.

```tsx
import { SlashMenu } from '@richkitjs/react'

<SlashMenu editor={editor} />
```
