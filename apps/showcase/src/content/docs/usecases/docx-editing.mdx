# Usecase: docx editing

The `@richkitjs/docx` package handles DOCX import and export against the same document
model as everything else — no separate "docx mode". This demo starts from an editable
NDA template and can round-trip it to a real `.docx` file.

<AgentPrompt prompt={DOCX_EDITING_PROMPT} />

```tsx
import { downloadDocx, importDocxFile } from '@richkitjs/docx'

// export
await downloadDocx(editor, { filename: 'document.docx' })

// import — replaces the document, returns any conversion warnings
const warnings = await importDocxFile(editor, file)
```
