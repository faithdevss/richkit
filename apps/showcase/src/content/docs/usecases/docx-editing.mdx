# Usecase: docx editing

The `@rich-editor/docx` package handles DOCX import and export against the same document
model as everything else — no separate "docx mode". This demo starts from an editable
NDA template and can round-trip it to a real `.docx` file.

```tsx
import { downloadDocx, importDocxFile } from '@rich-editor/docx'

// export
await downloadDocx(editor, 'document.docx')

// import
const doc = await importDocxFile(file)
editor.commands.setContent(doc)
```
