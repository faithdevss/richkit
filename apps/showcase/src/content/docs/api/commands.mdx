# API: Commands

Commands are how the document changes. Toolbar buttons, keyboard shortcuts, slash items
and programmatic edits all go through the same registry.

## Three ways to call one

```ts
// 1. single command
editor.commands.toggleBold()
editor.commands.setHeading({ level: 2 })

// 2. by name
editor.command('toggleBold')
editor.command('setHeading', { level: 2 })

// 3. chained
editor.chain().call('selectAll').call('toggleBold').focus().run()
```

All three return `boolean` — `false` when the command doesn't apply (or the name isn't
registered).

## The chain builder

`editor.chain()` returns a `CommandChainBuilder` with exactly three methods. It does
**not** proxy command names as methods, so `editor.chain().toggleBold()` is not a
function — use `.call('toggleBold')`.

| Method  | Signature                                    | Description                                                                               |
| ------- | -------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `call`  | `(name: string, ...args: unknown[]) => this` | Queues a command. Unknown names are silently skipped.                                     |
| `focus` | `() => this`                                 | Queues a focus step.                                                                      |
| `run`   | `() => boolean`                              | Executes the queue. **Stops at the first step that returns `false`** and returns `false`. |

Which command a button runs and which name it highlights on are separate: `toggleBold` is
the command, `bold` is the mark. That's why `ToolbarButton` has both `command` and
`isActiveName`.

## Writing your own

`addCommands` receives `{ name, options, editor }` and returns factories. Each factory
takes your arguments and returns a `Command` — a function of `{ state, tr, view, dispatch }`
returning `boolean`.

```ts
import { Extension, type Command } from '@richkitjs/core'

const Clear = Extension.create({
  name: 'clearDoc',
  addCommands: () => ({
    clearDoc:
      (): Command =>
      ({ state, dispatch }) => {
        if (dispatch) dispatch(state.tr.delete(0, state.doc.content.size))
        return true
      },
  }),
})
```

Return `false` when the command doesn't apply — that's what stops a chain and greys out a
toolbar button. Only mutate when `dispatch` is present; ProseMirror calls commands with a
null `dispatch` to test applicability.
