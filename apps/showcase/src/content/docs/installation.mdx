# Installation

Every package ships to the public npm registry under the
[`@richkitjs`](https://www.npmjs.com/org/richkitjs) scope, so any package manager installs it
with no extra registry config. Install the React binding and the starter kit:

</div>

<Install packages="@richkitjs/react @richkitjs/starter-kit" />

<div className="docs-prose">

Render an editor:

```tsx
import { useEditor, EditorContent } from '@richkitjs/react'
import { StarterKit } from '@richkitjs/starter-kit'

export function MyEditor() {
  const editor = useEditor({
    extensions: StarterKit,
    content: '<p>Hello world</p>',
  })

  return <EditorContent editor={editor} />
}
```

`useEditor` returns `null` on the first render (the `Editor` instance is created in an
effect) — `EditorContent` handles that automatically.

## Adding a toolbar

`@richkitjs/react` ships a default toolbar and the building blocks to compose your own:

```tsx
import { useEditor, EditorContent, Toolbar, DefaultToolbar } from '@richkitjs/react'
import { StarterKit } from '@richkitjs/starter-kit'

export function MyEditor() {
  const editor = useEditor({ extensions: StarterKit, content: '<p>Hello world</p>' })

  return (
    <>
      <Toolbar editor={editor}>
        <DefaultToolbar />
      </Toolbar>
      <EditorContent editor={editor} />
    </>
  )
}
```

## Picking extensions yourself

`StarterKit` is just an array of extensions — swap it for your own selection instead of
pulling in everything:

```tsx
import { Paragraph } from '@richkitjs/extension-paragraph'
import { Bold } from '@richkitjs/extension-bold'
import { Italic } from '@richkitjs/extension-italic'

const extensions = [Paragraph, Bold, Italic]
```

See the full [extensions reference](/docs/extensions) for every available package.
