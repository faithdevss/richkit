## Keyboard Shortcuts

- `Enter` — New block
- `Shift + Enter` — Line break
- `Backspace` — Merge/remove block
- `Ctrl/Cmd + B` — Bold
- `Ctrl/Cmd + I` — Italic
- `Ctrl/Cmd + U` — Underline
- `Ctrl/Cmd + K` — Add link
- `Ctrl/Cmd + Z` — Undo
- `Ctrl/Cmd + Shift + Z` — Redo
- `Escape` — Close menus
- Arrow keys — Navigate between blocks
